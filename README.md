# The Digital Detective

Welcome to **The Digital Detective**, a college assignment organized into nine missions. This repository is the initial project setup and will hold the documentation and work for each mission as the assignment progresses.

## Purpose

The purpose of this assignment is to explore foundational digital skills through a sequence of missions. Each mission focuses on a topic, with its own documentation to record the work and learning along the way.

## Mission Index

1. [Mission 00 — Setup](mission-00-setup/README.md)
2. [Mission 01 — Computer Basics](mission-01-computer-basics/README.md)
3. [Mission 02 — Terminal](mission-02-terminal/README.md)
4. [Mission 03 — Operating System](mission-03-operating-system/README.md)
5. [Mission 04 — Programs](mission-04-programs/README.md)
6. [Mission 05 — Numbers and Data](mission-05-numbers-data/README.md)
7. [Mission 06 — Git and GitHub](mission-06-git-github/README.md)
8. [Mission 07 — Networking](mission-07-networking/README.md)
9. [Mission 08 — Final Report](mission-08-final-report/README.md)

## Topics Covered

- Project setup and basic computer concepts
- Using the terminal and understanding operating systems
- Programs, numbers, and data
- Version control with Git and collaboration through GitHub
- Networking fundamentals
- Documenting and presenting learning in a final report

## Running the Number Converter

The number converter belongs to Mission 05. Once its implementation is in place, run it from the repository root with:

```bash
python3 mission-05-numbers-data/number_converter.py
```

## Mission Documentation and Commits

Each mission has a dedicated `README.md`. As the assignment progresses, document each mission in its README and commit that mission's work separately.

## Learning Summary

This project is intended to build practical familiarity with computers, command-line tools, programming concepts, data, version control, and networking. The mission documents will provide a place to capture what is learned throughout the assignment.
